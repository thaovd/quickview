# QuickView Markdown Preview

QuickView now has native **Markdown (.md)** rendering powered by **md4c** and **Direct2D**!

## Features

- **Headings** (H1, H2, H3, H4)
- **Styling**: **Bold**, *Italic*, and [links](https://github.com)
- **Lists**:
  1. Ultra fast memory-mapped file loading
  2. Zero chromium / webview2 dependency
  3. Crisp DirectWrite font rendering
- **Quotes**:
  > QuickView brings macOS Quick Look elegance to Windows 11 with instant spacebar preview.

## Code Example

```cpp
#include <iostream>

int main() {
    std::cout << "QuickView with native PDFium & md4c!" << std::endl;
    return 0;
}
```
